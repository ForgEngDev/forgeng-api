## Lifecycle and ownership

Begin with the chosen template's startup and scene definition. The 2D preset accepts scene definitions and provider configuration; action maps must be enabled, and a manually configured loop must be started. Dispose the action scope and scene subscriptions and destroy the game during teardown. Consult signatures before assuming a method is synchronous. Keep simulation in the template's fixed update path.

## Feature selection

Use preset declarations for game configuration; 2D authoring declarations for scene descriptions; action contracts for input bindings; provider contracts for optional services. Network and transport interfaces require explicit composition and do not provide a hosted multiplayer or signaling service. Advanced and composition entries are for integrations that have checked their runtime requirements.

## Compatibility

This complete snapshot is from local SDK 3.4.5. Public beginner templates are separately versioned. Their local declarations govern their running code. Deprecated or preview entries are retained exactly as the public package exposes them; their presence is not a recommendation to adopt them.
