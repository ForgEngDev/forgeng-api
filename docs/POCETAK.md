# Pocetak rada sa ForgeNG i AI asistentom

Izaberi jedan od templejta iz glavnog README fajla i napravi svoj GitHub repozitorijum pomocu dugmeta **Use this template**. Prati uputstvo templejta, pokreni `npm install`, zatim `npm run dev`, i proveri igricu u browseru koji podrzava WebGPU.

AI asistentu posalji:

> Procitaj https://github.com/ForgEngDev/forgeng-api i deklaracije u mom templejtu. Dodaj [opis funkcije] koristeci javni API. Zadrzi postojecu verziju engine-a i proveri rezultat komandom npm run build.

Ovaj repozitorijum daje modelima javne tipove i potpise funkcija. Implementacija engine-a ostaje privatna. GitHub sam po sebi ne ucitava dokumentaciju u svaki AI model: daj modelu link ili dodaj dokumentaciju u njegov kontekst.

Snapshot API-ja je 3.4.5. Templejt moze koristiti 3.4.2 ili drugu verziju; njegovi lokalni tipovi i runtime imaju prednost. Nemoj mesati verzije. Za prvi zadatak menjaj jednu stvar: brzinu igraca, raspored platformi, kameru ili prikaz poena. Posle build-a proveri igru, kontrole i greske u konzoli.
